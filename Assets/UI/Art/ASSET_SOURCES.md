# Menu asset sources

- Sky, paper flecks, cloud banks, celestial crest, ribbon shapes, irregular parchment cards, gold dividers, mouse illustrations, borders and keycaps: original project vector geometry in `Assets/UI/Scripts/StorybookGraphic.cs` and `StartMenuView.cs`. No imported reference-image crops or external image assets.
- Typography: Unity's bundled `LegacyRuntime.ttf`, loaded using `Resources.GetBuiltinResource<Font>`. Functional placeholder supplied with the engine; no redistributed font file. A final storybook display font remains an art-pass task and requires a recorded source and license before import.

All labels are live uGUI text. Illustrations remain separate non-interactive graphics. There are no additional third-party assets to reconcile into the shared credits at this stage.
